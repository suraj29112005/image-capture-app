# Image Capture App

A web application for capturing images and viewing saved media.

## Features
- Camera interface for image capture
- Gallery to view saved media
- Backend server for handling media

## Tech Stack
- React
- Vite
- Node.js
- Express.js

## Project Structure
- `camera-app/` – Camera interface
- `gallery-app/` – Media gallery
- `server/` – Backend server

## Getting Started
Clone the repository:

```bash
git clone https://github.com/suraj29112005/image-capture-app.git
cd image-capture-app
```

Install dependencies separately inside `camera-app`, `gallery-app`, and `server` using `npm install`.

Start each application using the scripts defined in its `package.json`.
